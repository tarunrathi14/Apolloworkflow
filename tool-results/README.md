# tool-results

Working artefacts from a weekly run, committed so a later fresh session can audit what was
actually filtered and saved rather than re-running the search (1 credit) to recover it.

- `search_d_page2_raw.json` — the 100 records Search D page 2 returned on 2026-10-07.
- `enriched_parsed.json` — the 30 enrichment records parsed out of the persisted
  `tool-results/*.txt|json` overflow files, reduced to the fields the four filters need.
- `created_builders.json` — created vs already-existing contacts from the builders save.
